# Step 6: Manual User Setup Guide

> **Temporary Solution:** Since we don't have authentication/login yet, we manually create a test user in Supabase and use that user_id when testing the API.

---

## 📋 Instructions: Create a Test User in Supabase

### **1. Open Supabase Dashboard**

1. Go to [https://supabase.com/dashboard](https://supabase.com/dashboard)
2. Log in to your account
3. Select your project

---

### **2. Navigate to the Users Table**

1. Click **"Table Editor"** in the left sidebar
2. Select the **"users"** table from the list

---

### **3. Insert a Test User**

1. Click the **"Insert"** button (or **"Insert row"**)
2. Fill in the fields:
   - **email**: `test@example.com`
   - **name**: `Test User`
3. Click **"Save"**

**Note:** The `id` field will be auto-generated by Supabase (UUID format)

---

### **4. Copy the User ID**

1. After saving, you'll see your new user in the table
2. **Copy the UUID** from the `id` column
   - Example: `a1b2c3d4-e5f6-7890-abcd-ef1234567890`
3. **Save this somewhere!** You'll need it for testing

---

## 🧪 Using the Test User ID

Now use this `user_id` when testing your API endpoints:

### **Example 1: Upload a Book**

```bash
curl -X POST "http://localhost:8000/api/v1/books/upload" \
  -F "file=@docs/sample_books/alice_in_wonderland.txt" \
  -F "user_id=a1b2c3d4-e5f6-7890-abcd-ef1234567890" \
  -F "title=Alice in Wonderland"
```

### **Example 2: Send a Chat Message**

```bash
curl -X POST "http://localhost:8000/api/v1/chat/message" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "message": "Who is Alice?"
  }'
```

### **Example 3: Get Chat History**

```bash
curl "http://localhost:8000/api/v1/chat/history/CHAT_ID_HERE"
```

---

## 💡 Alternative: Use Swagger UI

Instead of curl, you can test via the interactive API documentation:

1. Start your server: `python main.py`
2. Open browser: http://localhost:8000/docs
3. Click on an endpoint (e.g., "POST /api/v1/books/upload")
4. Click **"Try it out"**
5. Fill in the fields:
   - **user_id**: Paste your copied UUID
   - **file**: Select a book file
   - **title**: Enter a title
6. Click **"Execute"**

---
